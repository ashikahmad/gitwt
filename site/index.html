gitwt

Git worktrees,
by branch name.

gitwt is a small shell wrapper around git worktree for zsh and bash. Create a worktree and jump into it, switch by branch, move it, and remove it without losing your .env.

Install Read the guide 
$ gitwt new feature/dark-mode
Creating 'feature/dark-mode' from 'main' at: ~/code/worktrees/myapp/feature-dark-mode
Copied 1 file(s) listed in .worktreeinclude.
Running scripts/setup.sh...
installing dependencies...
Done! Switching into it now...

$ gitwt sw main
Switching to worktree: ~/code/myapp

$ gitwt remove feature/dark-mode
Error: removing this worktree would lose files listed in .worktreeinclude.
Changed here, so they differ from the main repo's copy. To compare:
  diff '/home/you/code/myapp/.env' '/home/you/code/worktrees/myapp/feature-dark-mode/.env'
To remove it anyway and lose them: gitwt remove feature/dark-mode --force

Why gitwt?

git worktree is powerful but awkward to use directly: full paths, separate commands to branch and attach, and nothing to remember where you put things.

1

Think in branches, not paths

Name a branch, such as gitwt sw feature/dark-mode, and gitwt finds the right folder for you.

2

Worktrees live outside your repo

Every worktree lands in one predictable place next to your repo, or wherever your gitwt.path template says.

3

One command, no switching first

gitwt new my-feature --from develop --fetch branches and creates the worktree from wherever you are.

What it does

Five commands, plus a little setup that makes new worktrees ready to use.

new

Create a worktree and cd into it. Works out whether to create the branch or attach an existing one.

switch · sw

Jump into any worktree by branch name, wherever it is.

remove

Tear down a worktree, and optionally its branch. Refuses if you'd lose uncommitted work or an edited .env.

move · mv

Move a worktree elsewhere, or keep its folder in step with a renamed branch. Everything in it moves as is.

list · ls

Every worktree with its branch, sync with upstream, local changes and path.

New worktree setup

Copy ignored files such as .env with .worktreeinclude, and run your setup script once you've approved it.

Custom paths

Put worktrees where you like with a gitwt.path template, per repo or for all repos.

Zsh completion

Commands, branches and flags complete with Tab.

Install

Clone it and run the installer. It adds gitwt to your ~/.zshrc or ~/.bashrc.

  • Needs git 2.18 or newer, and zsh or bash.
  • Tested with zsh 5.9 and bash 5.2. bash 3.2, the version macOS ships, isn't officially supported; macOS's default shell, zsh, is.
  • Installing by hand, updating, and everything else: the guide.
git clone https://github.com/ashikahmad/gitwt.git
cd gitwt
bash install.sh
source ~/.zshrc    # or: source ~/.bashrc
